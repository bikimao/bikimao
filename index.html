        Catatan penting

        Uang masuk tambahan otomatis dibagi 60% ke Dana Darurat dan 40% ke Tabungan.
        Sisa dana yang belum dialokasikan ke amplop kebutuhan otomatis masuk ke Dana Darurat dan Tabungan dengan rasio 60:40.
        Target Dana Darurat 6 Bulan dihitung dari rata-rata pengeluaran pokok (di luar amplop Dana Darurat dan Tabungan) selama maksimal 6 bulan terakhir yang tercatat, dikali 6.
        Saldo Dana Darurat dan Tabungan berlanjut dari bulan sebelumnya; saldo awal bisa Anda koreksi manual.
        Seluruh data disimpan dan dikelola lewat akun ID & Password yang Anda buat di browser ini. Data tiap akun terpisah, tidak dikirim ke server mana pun, dan password disimpan sebagai hash, bukan teks biasa.
        Akun terikat pada browser dan perangkat ini. Akun tidak muncul di browser atau perangkat lain, dan menghapus data situs browser akan menghapus akun beserta datanya.
        Lupa password atau ID? Pakai Lupa Password? (cukup dengan ID Akun) atau Lupa ID Akun? (daftar ID yang tersimpan) di layar masuk. Pemulihan hanya berlaku untuk akun yang tersimpan di browser dan perangkat ini, dan data keuangan tidak terhapus saat password diganti. Karena itu siapa pun yang bisa membuka browser ini bisa memakainya, jadi hindari perangkat bersama.

        Mutasi per bulan

        Bulan bertanda * belum punya data tersimpan dan dihitung dengan konfigurasi default bulanan. Pemasukan sudah termasuk uang masuk tambahan, dan saldo menumpuk dari bulan ke bulan.
